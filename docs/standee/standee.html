Project Brief

[cite: 43]

Long-form video is hard to search: keyword search misses intent, returns fragmented snippets, and forces manual scrubbing. NeuroClip is a context-aware web platform for students, educators, and teams who need to find moments in lectures, meetings, and archives using natural language. It ingests video (upload or URL), fuses speech (ASR) and **on-screen text (OCR)**, builds semantic embeddings, and returns playable clips — with optional privacy blurring and compression for sharing.

Objective

[cite: 46]
  • Develop a multimodal pipeline that fuses ASR transcripts and frame OCR into searchable sentence-level units.
    • [cite: 47]
  • Implement intent-aware semantic retrieval with vector search, re-ranking, and FFmpeg-based clip extraction.
    • [cite: 47]
  • Design query-driven privacy redaction (faces, IDs, license plates) and codec-aware video compression modules.
    • [cite: 47]
  • Evaluate retrieval quality using grounded test queries (Precision@K, nDCG@K) on diverse domains.
    • [cite: 47]
  • Deploy a secure Progressive Web Application with authentication, processing history, and reusable job-level caching.
